# 게임 개발과 플레이 개선 경험

Unity와 C#으로 진행한 개인·팀 프로젝트를 정리했습니다. Coin Survivor에서는 상점과 인벤토리 개발, 관련 밸런싱과 출시 후 플레이 개선 작업에 참여했습니다.

## 이번 지원 자료

[Coin Survivor 게임플레이 QA 포트폴리오](https://github.com/qqyq010/coin-survivor-qa)

담당 역할, 플레이 중 발견한 문제와 수정 과정, 코드 발췌, 밸런스 시트를 담았습니다. 이 저장소에서도 [동일한 QA 자료](portfolio/02-coin-laundry/qa/README.md)를 볼 수 있습니다.

Coin Survivor는 STOVE에 출시했으며 Steam 출시를 앞두고 있습니다.

## 자료 읽는 순서

1. 프로젝트 소개에서 맡은 역할과 게임 내용을 확인합니다.
2. 사례 문서에서 문제 상황과 이후 작업을 읽습니다.
3. 연결된 코드와 시트에서 관련 동작과 계산을 살펴봅니다.

개발과 코드 수정에는 AI 도구를 활용했습니다. 프로젝트별 문서에는 제가 맡은 영역과 제안·확인한 내용을 중심으로 적었습니다.
