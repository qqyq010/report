| 항목 | 내용 |
|---|---|
| 발생 화면 | 로비의 Upgrade 화면 |
| 기대한 표시 | 업그레이드 제목과 설명을 한글로 읽을 수 있음 |
| 실제 표시 | 영문 고정 글자는 보이지만 한글은 네모로 표시됨 |
| 플레이 영향 | 효과를 읽기 어려워 어떤 업그레이드를 선택할지 판단하기 어려움 |

수정 뒤 직접 같은 화면에 들어가 한글 제목과 설명이 정상적으로 보이는지 확인했습니다.
