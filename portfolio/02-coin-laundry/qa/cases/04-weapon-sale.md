# 무기를 판매해도 공격이 계속되는 문제

기능 버그 · 상점/인벤토리 · 2026년 5월 12일 개발 기록

## 발생 조건

구매하거나 합성한 2레벨 무기를 판매하면 인벤토리에서는 사라졌지만, 실제 장착된 무기와 공격이 남을 수 있었습니다. 아이템 보유 상태와 전투 상태가 서로 맞지 않는 문제였습니다.

당시 기록을 바탕으로 정리한 재현 순서입니다.

1. 구매 또는 합성으로 2레벨 무기를 준비합니다.
2. 해당 무기를 판매 대상으로 선택하고 판매를 확정합니다.
3. 인벤토리에서의 제거와 실제 장착 무기 상태를 함께 확인합니다.

| 구분 | 결과 |
|---|---|
| 기대 결과 | 판매한 무기가 인벤토리와 실제 장착 상태에서 모두 제거됨 |
| 실제 문제 | 인벤토리에서는 제거됐지만 장착 무기와 공격이 남을 수 있음 |
| 플레이 영향 | 보유하지 않은 무기로 공격하며 판매 결과와 전투 상태가 달라짐 |

## 수정 과정

판매 완료 알림은 있었지만 판매한 무기의 ID와 레벨을 실제 무기 제거 경로에 전달하지 않았습니다. 판매 성공 시 기존 제거 이벤트에 연결하고, 무기 종류에만 적용하도록 구분했습니다.

담당 기능의 수정 과정에 참여한 뒤 직접 플레이하며 결과를 확인했습니다. [현재 구현의 판매 처리 발췌](../code/weapon-sale.cs.txt)에는 이 연결이 남아 있습니다.

## 수정 후 확인

- 판매한 2레벨 무기가 제거되는지 확인했습니다.
- 같은 종류의 1레벨과 2레벨을 함께 보유한 상태에서 2레벨만 팔아 1레벨이 유지되는지 확인했습니다.
- 판매 확정·취소와 구매·자동 합성·수동 합성도 함께 확인했습니다.

당시 직접 플레이한 결과는 [확인표](../evidence/weapon-sale-checks.md)에 정리했습니다. 화면에서 아이템이 사라지는지와 실제 전투 상태를 함께 대조한 사례입니다.
