# 자석 효과의 획득 범위가 잘 느껴지지 않았습니다

플레이 체감 개선 · 2026년 7월 후속 작업

## 발견한 문제

자석 효과를 사용했는데도 아이템을 줍는 범위의 차이가 거의 느껴지지 않았습니다. 상황을 설명하고 코드 분석과 수정 과정을 거친 뒤, 7월 16일 다시 플레이하며 획득 범위가 나아진 것을 확인했습니다.

이 사례의 확인 대상은 실제 아이템 획득 범위의 체감 변화입니다. [진화 무기의 공격 범위 조정](05-evolved-weapons.md)은 별개의 사례입니다.

## 관련 코드

[획득 반경 계산](../code/magnet-range.cs.txt)은 기본 반경에 로비 업그레이드 비율을 적용하는 현재 구현의 일부입니다. 자석 패시브와 로비 업그레이드는 서로 다른 입력이므로 이 발췌만으로 당시 패시브 전체의 수정 전후를 보여주지는 않습니다.
