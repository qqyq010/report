# 무기 판매 수정 후 확인 기록

2026년 5월 12일 Unity Play Mode에서 직접 확인한 결과를 당시 개인 개발 로그에서 정리했습니다. 2026년 10월 1일 포트폴리오용으로 재구성한 표입니다.

| 확인 조건 | 당시 결과 |
|---|---|
| 2레벨 무기 판매 | 해당 레벨 무기만 제거됨 |
| 같은 종류의 1레벨·2레벨을 함께 보유하고 2레벨만 판매 | 1레벨 유지 |
| 판매 화면 확정·취소 | 정상 동작 |
| 빈 공간이 있는 상태에서 1레벨 무기 구매 | 실제 무기 장착 |
| 인벤토리가 가득 찬 상태에서 같은 1레벨 무기 구매 | 자동 합성 후 2레벨 무기로 교체 |
| 같은 종류의 1레벨 무기를 여러 개 보유한 상태에서 자동 합성 | 하나만 2레벨로 변경, 나머지 유지 |
| 수동 무기 합성 | 정상 동작 |
| 패시브 아이템 구매·판매·합성 | 정상 동작 |
| Unity 콘솔 | 신규 오류·경고 없음 |

방어구 구매·판매는 당시 테스트 가능한 아이템이 없어 확인하지 못했습니다.

출처는 2026-05-12 개인 개발 로그의 ‘weapon 자동 merge fallback / ItemType 이벤트 라우팅 Play Mode 검증 결과’입니다. 이 표는 당시 확인 범위를 요약한 기록이며 현재 버전을 새로 테스트한 결과는 아닙니다.
