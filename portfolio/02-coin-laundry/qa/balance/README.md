# 밸런스 조정안 v5

[Excel 파일](project2-balance-v5-ko.xlsx)을 함께 첨부했습니다. 2026년 7월 16일 기준의 코드·데이터와 비용 조정안을 정리한 12개 시트입니다.

[경제 사례](../cases/03-economy.md)에서는 114골드로 10골드 상품 네 개를 사면 74골드가 남아 100골드 확장을 선택할 수 없었던 상황을 설명합니다. 시트는 구매와 확장을 함께 선택할 여유를 주는 방향을 검토한 자료입니다.

1. **대시보드**: 문제 상황과 조정 목표
2. **경제 흐름 / 인벤토리 경제**: 골드·상점 진입·구매·확장 비용 관계
3. **현재 기준 / 성장 곡선**: 기준 수치와 계산
4. **플레이 모드 입력**: 실제 플레이 결과를 기록할 양식

노란 입력 칸은 플레이 측정값을 넣는 곳입니다. 판정에 필요한 지표가 빠지거나 숫자가 아니면 ‘미측정’으로 남습니다. 현재 기록하지 않은 측정값은 비워두었습니다.

첫 화면과 작업 문구, 누락 입력 판정은 제출용으로 정리했습니다. 경제 개선안과 실제 전투 조정 기록은 [진화 무기 사례](../cases/05-evolved-weapons.md)에서 구분해 볼 수 있습니다.
