# 밸런스 시트 v5

[project2-balance-v5-ko.xlsx](project2-balance-v5-ko.xlsx)는 구매 비용과 성장 흐름을 검토하며 정리한 개선안입니다. 12개 시트로 구성돼 있습니다.

다음 순서로 보면 상점·인벤토리 작업과 연결해 읽기 쉽습니다.

1. **대시보드 / 현재 기준**: 기준 규칙과 주요 수치
2. **경제 흐름 / 인벤토리 경제**: 상점 진입, 아이템 구매, 가방 확장의 비용 관계
3. **플레이 모드 입력**: 플레이 결과를 기록하는 입력 양식

저는 플레이 중 구매가 막히는 구간과 원하는 성장 흐름을 설명했습니다. 표 구성과 계산에는 AI 도구의 도움을 받았습니다.
