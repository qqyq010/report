# Coin Survivor — 개발 참여와 플레이 개선 경험

팀으로 개발해 STOVE에 출시했으며, Steam 출시도 앞두고 있는 게임입니다. 저는 상점과 인벤토리를 맡았습니다.

[STOVE 출시 페이지](https://store.onstove.com/ko/games/105249) / [Steam 스토어 페이지](https://store.steampowered.com/app/5034980/Coin_Survivor/)

## 맡은 일

Unity와 C#을 사용한 팀 프로젝트에서 상점과 인벤토리 개발을 맡았습니다. 평소 즐기던 게임들을 참고해 아이템 회전, 가방 확장, 합성 기능을 제안하고 가방과 상점 UI를 개발했습니다. 관련 비용과 성장 흐름을 조정하는 밸런싱에도 참여했습니다. 구현과 코드 수정에는 AI 도구를 활용했습니다. 개발 중에는 QA 팀원의 피드백을 받아 담당 기능을 수정했고, 프로젝트가 끝난 뒤에도 직접 플레이하며 수정할 부분을 찾았습니다.

## 플레이하면서 발견한 것

| 사례 | 문제 상황 | 이후 작업 |
|---|---|---|
| [자석 효과](cases/01-magnet.md) | 사용해도 획득 범위의 차이가 잘 느껴지지 않음 | 수정 후 다시 플레이해 획득 범위가 넓어진 것을 확인 |
| [한글 표시](cases/02-ui-text.md) | 업그레이드 제목과 설명이 네모로 표시됨 | 수정 후 같은 화면에서 정상 표시 확인 |
| [구매·성장 흐름](cases/03-economy.md) | 확장 비용 때문에 아이템을 사기 어려움 | 구매 선택이 막히는 구간을 설명하고 비용·성장 구조 개선안 검토 |

플레이 중 발견한 오버밸런스 문제도 추가로 수정했습니다.
