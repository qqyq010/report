## 개발과 밸런싱

평소 즐기던 게임들을 참고해 아이템 회전, 가방 확장, 합성 기능을 제안하고 가방과 상점 UI를 개발했습니다. 구현과 코드 수정에는 AI 도구를 활용했으며, 개발 중에는 QA 팀원의 피드백을 받아 담당 기능을 수정했습니다.

아이템을 사고 나면 가방을 확장할 골드가 부족해 장비를 더 넣기 어려운 구간이 있었습니다. 보유 골드와 구매·확장 비용을 비교하고, 초반에도 구매와 확장을 함께 선택할 수 있도록 비용 조정안을 정리했습니다.
