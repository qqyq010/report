# 밸런스와 작업 확인

밸런스 수치는 시트의 계산과 데이터 변환 과정으로 정리했습니다. 변환된 데이터의 형식과 값 범위를 검사하고, 관련 문서와 작업 기록을 함께 관리했습니다.

## 확인할 때 구분한 내용

| 확인 대상 | 살펴본 내용 |
|---|---|
| 코드 | 요청·응답과 데이터 반영 흐름 |
| 빌드 | 코드와 관련 테스트의 결과 |
| 직접 실행 | 화면 조작 후 표시와 데이터 변화 |
| 서버 연결 | 실제 요청과 응답 결과 |

작업 기록에서 각 확인 결과를 따로 적어 서로 다른 결과가 같은 완료 상태로 읽히지 않도록 했습니다.
